# FUTpedia chilena

Aplicación móvil desarrollada con Expo Router, React Native, TypeScript y NativeWind.

## Iniciar

```bash
npm install
npx expo start -c
```

## Recursos históricos

- `assets/images/clubs/`: logos históricos organizados por club, conservando nombres y subcarpetas originales.
- `assets/images/decades/`: imágenes de décadas para el futuro módulo El Túnel.

La aplicación inicia con una pantalla mínima. El desarrollo funcional comienza por el módulo Clubes.
